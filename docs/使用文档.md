## 快速上手

### 第一步：安装打包机

1. 下载 `uniapppack_setup.exe` 安装包
2. 双击运行安装程序
3. 按照向导完成安装（可自定义安装路径）
4. 启动"懒猿 UniAPP 打包机"

### 第二步：配置环境

首次使用需要配置打包环境，点击右上角的 **设置图标** 进入配置窗口。

![设置按钮位置](https://via.placeholder.com/800x100?text=设置按钮在右上角)

## 环境配置

### 基础配置

#### 1. HBuilderX 地址
- **作用**: 用于读取 uni-app x 离线 SDK 和项目配置
- **路径示例**: `C:\HBuilderX`
- **如何获取**: 
  1. 下载并安装 [HBuilderX](https://www.dcloud.io/hbuilderx.html)
  2. 选择 HBuilderX 的安装根目录

#### 2. 打包临时文件目录
- **作用**: 存放生成的原生工程和临时构建文件
- **路径示例**: `D:\uniapp_pack_temp`
- **建议**: 选择磁盘空间充足的目录（建议预留 5GB 以上）

### Android 配置

#### 1. 安卓离线 SDK 地址

**下载地址**: [uni-app x Android 离线 SDK](https://doc.dcloud.net.cn/uni-app-x/native/download/android.html)

**配置步骤**:
1. 下载对应版本的离线 SDK 压缩包（如 `uni-app-x_5.07_Android.zip`）
2. 解压到本地目录（如 `D:\uni-sdk\android-5.07`）
3. 在配置窗口选择解压后的目录
4. 版本号会自动识别（如 `5.07`），也可手动输入

**目录结构要求**:
```
uni-app-x_5.07_Android/
├── SDK/
│   ├── libs/          # 必须包含
│   └── ...
└── plugins/           # 必须包含
```

#### 2. 安卓 SDK 地址

**如何获取**:
- 通过 Android Studio SDK Manager 下载
- 或从 [Android 开发者官网](https://developer.android.com/studio) 下载命令行工具

**路径示例**: `C:\Users\用户名\AppData\Local\Android\Sdk`

**必需组件**:
- Android SDK Platform（如 API 33）
- Android SDK Build-Tools（如 33.0.0）
- Android SDK Platform-Tools

#### 3. JDK 地址

**推荐版本**: JDK 17

**下载地址**: 
- [Oracle JDK](https://www.oracle.com/java/technologies/downloads/)
- [OpenJDK](https://adoptium.net/)

**路径示例**: `C:\Program Files\Java\jdk-17`

#### 4. Gradle 路径

**推荐版本**: Gradle 7.4+

**下载地址**: [Gradle Releases](https://gradle.org/releases/)

**配置步骤**:
1. 下载 Binary-only 版本
2. 解压到本地目录（如 `D:\gradle-8.0`）
3. 选择解压后的根目录

**路径示例**: `D:\gradle-8.0`

#### 5. Android Studio 路径（可选）

**作用**: 用于后续调试和开发

**路径示例**: `C:\Program Files\Android\Android Studio`

### iOS 配置（仅 macOS）

#### 1. iOS 离线 SDK 地址

**下载地址**: [uni-app x iOS 离线 SDK](https://doc.dcloud.net.cn/uni-app-x/native/download/ios.html)

**配置步骤**:
1. 下载对应版本的离线 SDK（如 `uni-app-x_5.07_iOS.zip`）
2. 解压到本地目录（如 `/Users/username/uni-sdk/ios-5.07`）
3. 在配置窗口选择解压后的目录
4. 版本号会自动识别

**目录结构要求**:
```
uni-app-x_5.07_iOS/
├── UniAppXDemo/       # 基础工程
├── SDK/              # 必须包含
└── TemporarySampleFramework/  # 必须包含
```

#### 2. Xcode 路径（可选）

**作用**: 用于后续编译和签名

**路径示例**: `/Applications/Xcode.app`

## uni-app x 打包

### 前置准备

#### 1. 在 HBuilderX 中本地发行

**重要**: 打包机需要基于 HBuilderX 本地发行生成的资源进行打包。

**Android 发行步骤**:
1. 在 HBuilderX 中打开你的 uni-app x 项目
2. 点击菜单: `发行` → `原生App-本地打包` → `生成本地打包App资源`
3. 选择 Android 平台
4. 等待发行完成，确认生成了 `项目目录/unpackage/resources/app-android` 文件夹

**iOS 发行步骤**:
1. 同上，选择 iOS 平台
2. 确认生成了 `项目目录/unpackage/resources/app-ios` 文件夹

#### 2. 准备证书文件（Android）

**证书类型**: 
- 自选证书（.keystore 或 .jks 文件）

**如何生成证书**（如果没有）:
```bash
keytool -genkey -alias myapp -keyalg RSA -keysize 2048 -validity 36500 -keystore myapp.keystore
```

按提示输入：
- 证书密码（storePassword）
- 证书库密码（keyPassword）
- 组织信息等

### Android 打包流程

#### 1. 选择项目

点击 **选择文件夹** 按钮，选择你的 uni-app x 项目根目录（包含 `manifest.json` 的目录）。

#### 2. 选择打包类型

- **自定义基座**: 用于开发调试，包名固定，生成 `android_debug.apk`
- **正式打包**: 用于发布，需要配置正式证书

#### 3. 填写 Android 配置

| 配置项 | 说明 | 示例 |
|--------|------|------|
| 包名 | Android 应用包名，建议使用反域名格式 | `com.example.myapp` |
| 证书类型 | 目前仅支持自选证书 | 自选证书 |
| 证书文件 | .keystore 或 .jks 文件路径 | 点击选择文件 |
| 证书别名 | 生成证书时设置的 alias | `myapp` |
| 证书库密码 | 证书 storePassword | - |
| 证书密码 | 证书 keyPassword | - |
| 原生库冲突处理 | （可选）解决 .so 文件冲突 | `lib/*/libc++_shared.so` |

**原生库冲突说明**:
- 当打包时出现类似 `More than one file was found with OS independent path 'lib/arm64-v8a/xxx.so'` 的错误时填写
- 多个路径用英文逗号分隔
- 留空表示不启用

#### 4. 开始打包

点击 **打包** 按钮，打包窗口会自动弹出并显示实时日志。

**打包流程**:
1. 校验环境配置
2. 生成原生 Android 工程
3. 合并离线 SDK 和项目资源
4. 执行 Gradle 构建
5. 签名 APK
6. 复制到输出目录

**输出位置**:
- **正式包**: `打包临时目录/_包名.apk`
- **自定义基座**: `项目目录/unpackage/debug/android_debug.apk`

### iOS 打包流程（macOS）

#### 1. 选择项目

点击 **选择文件夹** 按钮，选择你的 uni-app x 项目根目录。

#### 2. 选择打包类型

- **自定义基座**: 开发调试用
- **正式打包**: 生产发布用

#### 3. 填写 iOS 配置

| 配置项 | 说明 | 示例 |
|--------|------|------|
| Bundle ID | iOS 应用唯一标识 | `com.example.myapp` |
| 渠道 | 发布渠道 | `appstore`（默认） |
| 广告联盟ID | （可选）开通 uniad 时填写 | - |
| 隐私弹窗 | 首次启动是否默认同意隐私协议 | 默认同意 / 不默认同意 |

#### 4. 生成工程

点击 **生成工程** 按钮。

**生成流程**:
1. 校验环境配置
2. 生成 iOS 原生工程
3. 合并离线 SDK 和项目资源
4. 修改 Info.plist 和启动配置
5. 自动打开生成目录

**输出位置**: `打包临时目录/包名/uniappx-native-ios`

#### 5. 后续步骤（需手动操作）

1. 在生成的目录中找到 `.xcworkspace` 或 `.xcodeproj` 文件
2. 使用 Xcode 打开工程
3. 配置签名证书和 Provisioning Profile
4. 选择目标设备或模拟器
5. 点击 Run 或 Archive 编译生成 IPA

## 传统 uni-app 打包

传统 uni-app 的打包流程与 uni-app x 类似，主要区别：

### Android
- 发行资源目录为 `unpackage/resources/__UNI__xxx`（非 `app-android`）
- 其他配置项相同

### iOS
- 发行资源目录为对应的传统 uni-app iOS 资源
- 仅生成工程，不执行编译

**注意**: 传统 uni-app 功能为占位实现，部分特性可能需要进一步完善。

## 常见问题

### 1. 打包失败：找不到 `app-android` 资源

**原因**: 未在 HBuilderX 中执行本地发行。

**解决**:
1. 打开 HBuilderX
2. 菜单: `发行` → `原生App-本地打包` → `生成本地打包App资源`
3. 等待发行完成
4. 重新打包

### 2. Gradle 构建失败

**常见原因**:
- Gradle 版本不兼容
- 网络问题导致依赖下载失败
- JDK 版本不匹配

**解决方法**:

**方法 1: 配置 Gradle 镜像**

编辑 `打包临时目录/包名/uniappx-native-android/build.gradle`:
```gradle
allprojects {
    repositories {
        maven { url 'https://maven.aliyun.com/repository/public/' }
        maven { url 'https://maven.aliyun.com/repository/google/' }
        google()
        mavenCentral()
    }
}
```

**方法 2: 检查 JDK 版本**
```bash
java -version
```
确保使用 JDK 17。

**方法 3: 手动构建**
1. 打开生成的原生工程目录
2. 使用 Android Studio 打开
3. 等待 Gradle 同步完成
4. 点击 Build → Build Bundle(s) / APK(s) → Build APK(s)

### 3. 证书密码错误

**症状**: 打包时提示 `Keystore was tampered with, or password was incorrect`

**解决**:
- 确认证书密码和证书库密码填写正确
- 确认证书别名正确
- 尝试重新生成证书

### 4. iOS 工程生成后无法编译

**常见原因**:
- 签名配置未完成
- Xcode 版本过低
- SDK 版本不匹配

**解决**:
1. 在 Xcode 中选择 `Signing & Capabilities`
2. 配置 Team 和 Provisioning Profile
3. 确保 Bundle ID 与配置一致
4. 检查 Deployment Target 是否符合要求

### 5. 原生库冲突（.so 文件冲突）

**症状**: 
```
More than one file was found with OS independent path 'lib/arm64-v8a/libc++_shared.so'
```

**解决**:
在 **原生库冲突处理** 输入框中填写冲突路径:
```
lib/*/libc++_shared.so
```

多个路径用逗号分隔:
```
lib/*/libc++_shared.so, lib/*/libother.so
```

### 6. 配置保存后再次打开丢失

**原因**: 配置文件权限问题或路径异常。

**解决**:
1. 以管理员身份运行打包机
2. 检查 `%APPDATA%\uniapppack\config.json` 是否可写
3. 重新配置环境

### 7. 打包日志乱码

**原因**: Gradle 输出编码与系统不一致。

**解决**: 暂无影响，可忽略。如需解决，可在生成的 `gradle.properties` 中添加:
```properties
org.gradle.jvmargs=-Dfile.encoding=UTF-8
```

## 高级配置

### 自定义 Gradle 配置

生成的 Android 工程位于 `打包临时目录/包名/uniappx-native-android`，可以手动修改:

#### 1. 修改 compileSdkVersion

编辑 `app/build.gradle`:
```gradle
android {
    compileSdkVersion 33  // 修改此处
    // ...
}
```

#### 2. 添加依赖

```gradle
dependencies {
    implementation 'com.example:library:1.0.0'
}
```

#### 3. 配置混淆

编辑 `app/proguard-rules.pro`:
```proguard
-keep class com.example.** { *; }
```

### 自定义 iOS 工程配置

生成的 iOS 工程位于 `打包临时目录/包名/uniappx-native-ios`，可以在 Xcode 中:

#### 1. 修改 Info.plist
- 添加权限描述（相机、相册、定位等）
- 配置 URL Scheme

#### 2. 配置 Capabilities
- Push Notifications
- In-App Purchase
- Sign in with Apple

#### 3. 添加 Framework
- 在 General → Frameworks, Libraries, and Embedded Content 中添加

### 项目配置数据库

项目配置（证书信息等）保存在 SQLite 数据库中:

**位置**: `%APPDATA%\uniapppack\subject.db`（Windows）

**表结构**:
```sql
CREATE TABLE subject (
    path TEXT PRIMARY KEY,  -- 项目路径
    config TEXT             -- JSON 格式配置
);
```

可使用 SQLite 工具手动编辑或备份。

### 环境变量配置

打包机支持通过环境变量覆盖部分配置:

```bash
# Windows (cmd)
set JAVA_HOME=C:\Program Files\Java\jdk-17
set ANDROID_HOME=C:\Users\用户名\AppData\Local\Android\Sdk

# macOS / Linux
export JAVA_HOME=/Library/Java/JavaVirtualMachines/jdk-17.jdk/Contents/Home
export ANDROID_HOME=~/Library/Android/sdk
```
